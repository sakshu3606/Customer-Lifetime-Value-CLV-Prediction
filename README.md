# 📊 Customer Lifetime Value (CLV) Prediction

## 🚀 Project Overview
Customer Lifetime Value (CLV) Prediction is a Machine Learning project designed to predict the future value of customers based on their purchasing behavior, engagement, and transaction history. This project helps businesses identify high-value customers, improve customer retention strategies, and make data-driven business decisions.

The project compares multiple regression algorithms to determine the best-performing model for customer lifetime value prediction.
